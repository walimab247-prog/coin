Frequently Asked Questions

Common questions about Polkadot, DOT, decentralized oracles, and this website's editorial stance.

Polkadot is a layer-0 blockchain network launched in 2020 that connects specialized blockchains (parachains) into one interoperable system. All connected chains share the security of a common validator set on the relay chain.

DOT is Polkadot's native token. It is used for staking to secure the network, voting in on-chain governance (OpenGov), and paying for network resources such as coretime. This description is functional, not an assessment of value.

An oracle is infrastructure that delivers off-chain data — prices, event outcomes, sensor readings — to on-chain smart contracts. Decentralized oracle networks use many independent node operators and aggregation to reduce single points of failure.

Key risks include stale or lagging data, manipulation of thin underlying markets, compromised data sources, node collusion, and software bugs. Applications inherit the trust assumptions of every feed they consume. See our Risks page for details.
